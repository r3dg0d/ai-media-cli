# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | yes       |

## Reporting a vulnerability

Email the maintainer privately (GitHub: [@r3dg0d](https://github.com/r3dg0d))
or open a draft security advisory on the repository.

Please include:

- Affected component / CLI
- Reproduction steps (no secrets in public issues)
- Impact assessment

We aim to acknowledge reports within 7 days.

## Scope notes

- This project runs local inference; treat model checkpoints as untrusted input.
- Do not file issues requesting cloud exfiltration, credential theft, or malware.
